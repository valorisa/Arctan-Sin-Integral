Trigonométrie : fonctions, réciproques et identités

Ce document récapitule les fonctions trigonométriques circulaires, leurs inverses multiplicatifs, leurs fonctions réciproques, les identités fondamentales et les fonctions hyperboliques associées.

Attention à la notation : sin⁻¹(x) désigne généralement arcsin(x), la fonction réciproque du sinus. Ce n’est pas 1/sin(x), qui s’écrit csc(x).

Fonctions trigonométriques circulaires

Fonction Notation Définition en sin, cos Inverse multiplicatif Domaine usuel
Sinus sin θ y sur le cercle unité csc θ = 1/sin θ ℝ
Cosinus cos θ x sur le cercle unité sec θ = 1/cos θ ℝ
Tangente tan θ sin θ / cos θ cot θ = 1/tan θ cos θ ≠ 0
Cotangente cot θ cos θ / sin θ tan θ = 1/cot θ sin θ ≠ 0
Sécante sec θ 1/cos θ cos θ = 1/sec θ cos θ ≠ 0
Cosécante csc θ 1/sin θ sin θ = 1/csc θ sin θ ≠ 0

Fonctions réciproques

Les fonctions réciproques renvoient un angle, contrairement à sec, csc et cot, qui sont des inverses multiplicatifs.

Fonction réciproque Notations Définition Domaine Image principale
Arc sinus arcsin x, sin⁻¹ x y = arcsin x ⟺ x = sin y [-1, 1] [-π/2, π/2]
Arc cosinus arccos x, cos⁻¹ x y = arccos x ⟺ x = cos y [-1, 1] [0, π]
Arc tangente arctan x, tan⁻¹ x y = arctan x ⟺ x = tan y ℝ (-π/2, π/2)
Arc cotangente arccot x, cot⁻¹ x y = arccot x ⟺ x = cot y ℝ Dépend de la convention, souvent (0, π)
Arc sécante arcsec x, sec⁻¹ x y = arcsec x ⟺ x = sec y (-∞, -1] ∪ [1, +∞) Dépend de la convention
Arc cosécante arccsc x, csc⁻¹ x y = arccsc x ⟺ x = csc y (-∞, -1] ∪ [1, +∞) Dépend de la convention

Identités fondamentales

Famille Identités
Pythagore sin²θ + cos²θ = 1
Pythagore 1 + tan²θ = sec²θ
Pythagore 1 + cot²θ = csc²θ
Quotients tan θ = sin θ / cos θ, cot θ = cos θ / sin θ
Réciproques csc θ = 1/sin θ, sec θ = 1/cos θ, cot θ = 1/tan θ
Parité sin(-θ) = -sin θ, cos(-θ) = cos θ, tan(-θ) = -tan θ
Périodicité sin(θ + 2π) = sin θ, cos(θ + 2π) = cos θ, tan(θ + π) = tan θ
Addition sin(a ± b) = sin a cos b ± cos a sin b
Addition cos(a ± b) = cos a cos b ∓ sin a sin b
Addition tan(a ± b) = (tan a ± tan b) / (1 ∓ tan a tan b)
Double angle sin(2θ) = 2 sin θ cos θ, cos(2θ) = cos²θ - sin²θ

Exemple : relation entre sec² et 1/cos²

Par définition :

sec θ = 1 / cos θ

Donc :

sec²θ = (1 / cos θ)² = 1 / cos²θ

Cette égalité est valable uniquement si cos θ ≠ 0.

Fonctions hyperboliques

Les fonctions hyperboliques sont les analogues des fonctions trigonométriques circulaires, mais définies à partir de l’exponentielle.

Fonction Notation Définition Inverse multiplicatif
Sinus hyperbolique sinh x (eˣ - e⁻ˣ) / 2 csch x = 1/sinh x
Cosinus hyperbolique cosh x (eˣ + e⁻ˣ) / 2 sech x = 1/cosh x
Tangente hyperbolique tanh x sinh x / cosh x coth x = 1/tanh x
Cotangente hyperbolique coth x cosh x / sinh x tanh x = 1/coth x
Sécante hyperbolique sech x 1/cosh x cosh x = 1/sech x
Cosécante hyperbolique csch x 1/sinh x sinh x = 1/csch x

Fonctions réciproques hyperboliques

Fonction Notations usuelles Définition
Argument sinus hyperbolique arsinh x, asinh x, sinh⁻¹ x y = arsinh x ⟺ x = sinh y
Argument cosinus hyperbolique arcosh x, acosh x, cosh⁻¹ x y = arcosh x ⟺ x = cosh y, avec x ≥ 1
Argument tangente hyperbolique artanh x, atanh x, tanh⁻¹ x y = artanh x ⟺ x = tanh y, avec -1 < x < 1
Argument cotangente hyperbolique arcoth x, acoth x, coth⁻¹ x y = arcoth x ⟺ x = coth y, avec |x| > 1
Argument sécante hyperbolique arsech x, asech x, sech⁻¹ x y = arsech x ⟺ x = sech y, avec 0 < x ≤ 1
Argument cosécante hyperbolique arcsch x, acsch x, csch⁻¹ x y = arcsch x ⟺ x = csch y, avec x ≠ 0

Pièges fréquents

  • sec θ est l’inverse multiplicatif du cosinus : sec θ = 1/cos θ.
  • csc θ est l’inverse multiplicatif du sinus : csc θ = 1/sin θ.
  • cot θ est l’inverse multiplicatif de la tangente : cot θ = 1/tan θ.
  • arccos x est la réciproque du cosinus restreint à [0, π] : elle renvoie un angle.
  • cos⁻¹ x signifie habituellement arccos x, et non 1/cos x.
  • Les identités ne sont valables que lorsque les dénominateurs concernés sont non nuls.
